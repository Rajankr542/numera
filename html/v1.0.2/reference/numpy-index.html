NumPy name index

Every public NumPy 2.5.3 name that numera tracks, with its JavaScript equivalent in v1.0.2. 1045 are implemented and 9 are not yet. Names marked documented have a full reference entry with an example. For the others, open signature to see the TypeScript declaration, and follow the NumPy link for the semantics, which numera mirrors.

The JavaScript name is the NumPy name in camelCase, and Python keyword arguments become an options object. The compatibility page lists every documented difference from NumPy.
