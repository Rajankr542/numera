np.fillDiagonal

#
np.fillDiagonal(a, val, [options])

Fills the main diagonal of a in place (values repeat cyclically). For tall 2-D arrays, wrap: true restarts the diagonal after every ncols + 1 rows, like NumPy.

NumPynumpy.fill_diagonal

Parameters

aNDArray
Writeable array, at least 2-D (all sides equal when > 2-D).
valArrayLike
Scalar or values to write.
[options.wrap]boolean
Default false.

Returns

void

Example

TypeScript
const a = np.zeros([3, 3]);
np.fillDiagonal(a, [1, 2]);
a; // => [[1, 0, 0], [0, 2, 0], [0, 0, 1]]
const b = np.zeros([5, 2]);
np.fillDiagonal(b, 7, { wrap: true });
b; // => [[7, 0], [0, 7], [0, 0], [7, 0], [0, 7]]
TypeScript declaration
np.fillDiagonal(a: NDArray, val: ArrayInput, options?: { wrap?: boolean | undefined; } | undefined): void
