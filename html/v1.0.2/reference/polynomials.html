Polynomials

np.poly

#
np.poly(seqOfZeros)

Coefficients of the monic polynomial with the given roots, or the characteristic polynomial of a square matrix. Returns 1 when there are no roots. Conjugate-pair roots give real coefficients.

NumPynumpy.poly

Parameters

Roots (1-D) or a square matrix.

Returns

Example

np.poly([]); // => 1

np.polyfit

#
np.polyfit(x, y, deg, [options])

Least-squares polynomial fit of degree deg, coefficients highest power first. y may be 2-D (one fit per column). With full, returns [c, residuals, rank, singularValues, rcond]; with cov, returns [c, covariance]. A rank-deficient fit emits a RankWarning.

NumPynumpy.polyfit

Parameters

xArrayLike
Sample points (1-D).
yArrayLike
Values, 1-D or 2-D.
degnumber
Degree of the fit.
[options.rcond]number
Singular value cutoff (default len(x) * eps).
[options.full]boolean
Return diagnostic values too.
[options.w]ArrayLike
Weights.
[options.cov]boolean | "unscaled"
Return the covariance matrix too.

Returns

NDArray | Array

Example

TypeScript
np.allclose(np.polyfit([0, 1, 2], [1, 3, 5], 1), [2, 1]); // => true
TypeScript declaration
np.polyfit(x: ArrayLike, y: ArrayLike, deg: number, options?: PolyfitOptions | undefined): NDArray | (number | NDArray)[]

np.poly1d

#
new np.poly1d(c, [options])

A polynomial object. Leading zeros are trimmed. Python operators are methods: call(x), add, sub, mul, div (a scalar, or a polynomial giving [q, r]), pow, neg, equals. get(k) and set(k, v) read and write the coefficient of x**k. Also available: coeffs, order, length, roots, variable, integ(m, k), deriv(m), iteration over the coefficients, and toString(), which matches NumPy's str(p).

NumPynumpy.poly1d

Parameters

cArrayLike | poly1d
Coefficients, highest power first (or roots with r: true).
[options.r]boolean
Treat c as roots.
[options.variable]string
Variable name for printing (default "x").

Returns

poly1d

Example

TypeScript
const p = new np.poly1d([1, -2, 3]);
p.call(2); // => 3
p.mul(p).coeffs; // => [1, -4, 10, -12, 9]
p.deriv().coeffs; // => [2, -2]
String(p); // => "   2\n1 x - 2 x + 3"
TypeScript declaration
new np.poly1d(cOrR: PolyLike, options?: boolean | Poly1dOptions | undefined)
