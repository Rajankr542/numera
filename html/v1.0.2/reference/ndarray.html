API reference

NDArray

Every function returns an NDArray, a handle to data held in native memory. Read the values with toArray(), item() or toTypedArray().

a.toArray

#
a.toArray()

Copies the data into nested JS arrays. int64/uint64 values beyond 2^53 lose precision; use toTypedArray() for those. Complex arrays throw NotImplementedError; use toTypedArray() to read them.

Returns

NestedArray

Example

TypeScript
np.arange(4).reshape(2, 2).toArray(); // => [[0, 1], [2, 3]]

a.view

#
a.view([dtype])

A new view of the same memory, optionally reinterpreted as another dtype. With a different item size the last axis is rescaled; it must be contiguous and its byte size divisible by the new item size (otherwise ValueError, as NumPy).

a.view().base === a;       // => true

a.flat

#
a.flat

A FlatIter: a 1-D, C-order view of the elements. flat.get(i) takes an integer (returns a JS scalar), a slice tuple, an integer index array or a boolean mask (returns a new array); flat.set(i, value) repeats value cyclically over the selection; a.flat = v assigns to every element. It is also iterable, and has base, index, coords, length and copy().

NumPynumpy.ndarray.flat

Returns

FlatIter

Example

TypeScript
const a = np.array([[1, 2], [3, 4]]);
a.T.flat.get(1);      // => 3
a.flat.get([1, 4]);   // => [2, 3, 4]
a.flat.set(np.array([0, 3]), [9, 8]);
a.toArray();          // => [[9, 2], [3, 8]]
[...a.T.flat];        // => [9, 3, 2, 8]
TypeScript declaration
a.flat: FlatIter
