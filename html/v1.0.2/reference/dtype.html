API reference

Data types

Supported: bool, int8, int16, int32, int64, uint8, uint16, uint32, uint64, float16, float32, float64, complex64 and complex128. Each one is available as np.<name>, and anywhere a DTypeLike is accepted you can pass the name as a string. NumPy aliases float, double, single, half, int, complex and bool_ are also accepted.

np.dtype

#
np.dtype(like)

Resolves a name or DType to the canonical DType singleton, which has name, kind (b/i/u/f/c), itemSize and alignment. Unknown names throw DTypeError.

NumPynumpy.dtype

Parameters

likeDTypeLike
Name, alias or DType.

Returns

DType

Example

TypeScript
const d = np.dtype("single");
d.name;              // => "float32"
d.kind;              // => "f"
d.itemSize;          // => 4
d === np.float32;    // => true
TypeScript declaration
np.dtype(like: DTypeLike): DType

np.canCast

#
np.canCast(from, to, casting = "safe")

Whether from can be cast to to under a NumPy casting rule: "no", "equiv", "safe" (the default), "same_kind" or "unsafe". from can be a dtype or an array, in which case only its dtype is used. JS numbers raise DTypeError, as Python scalars do in NumPy 2. An unknown rule raises ValueError.

NumPynumpy.can_cast

Parameters

fromDTypeLike | NDArray
Source dtype, or an array whose dtype is used.
toDTypeLike
Target dtype.
castingstring
Casting rule.

Returns

boolean

Example

TypeScript
np.canCast("int8", "int16");                   // => true
np.canCast("float64", "float32");              // => false
np.canCast("float64", "float32", "same_kind"); // => true
np.canCast("int64", "uint8", "same_kind");     // => false
TypeScript declaration
np.canCast(from: DTypeLike | { readonly dtype: DType; }, to: DTypeLike, casting?: Casting | undefined): boolean

np.finfo

#
np.finfo(dtype | array)

Machine limits of a float dtype (complex: of its component). Fields as NumPy in camelCase: bits, eps, epsneg, max, min, tiny, smallestNormal, smallestSubnormal, resolution, precision, iexp, nexp, nmant, machep, negep, minexp, maxexp, dtype. Values are JS numbers holding the dtype's value. Non-float dtypes raise ValueError.

NumPynumpy.finfo

Returns

FInfo

Example

TypeScript
np.finfo("float16").max;  // => 65504
np.finfo("float32").nmant; // => 23
np.finfo("float64").eps;   // => 2.220446049250313e-16
TypeScript declaration
np.finfo(dt: NDArray | DTypeLike): FInfo

#
np.iinfo(dtype | array)

Limits of an integer dtype: bits, min, max, dtype, kind; min/max are numbers (lossy beyond 2^53) and minExact/maxExact exact bigints. Non-integer dtypes raise ValueError.

NumPynumpy.iinfo

Returns

IInfo

Example

TypeScript
np.iinfo("int8").min;   // => -128
np.iinfo("uint16").max; // => 65535
np.iinfo("uint64").maxExact === 18446744073709551615n; // => true
TypeScript declaration
np.iinfo(dt: NDArray | DTypeLike): IInfo

np.resultType

#
np.resultType(...arraysAndDtypes)

The dtype NumPy's type promotion gives. DTypes, dtype names and arrays are promoted with promoteTypes; JS scalars are weak (NEP 50): they can raise the kind (int → float → complex) but not the size.

NumPynumpy.result_type

Returns

DType

Example

TypeScript
np.resultType("int8", 300).name;          // => "int8"
np.resultType("int8", 1.5).name;          // => "float64"
np.resultType("float32", np.complex(0, 1)).name; // => "complex64"
np.resultType("int8", "uint8").name;      // => "int16"
TypeScript declaration
np.resultType(...args: (NDArray | NestedArray | DTypeLike)[]): DType

np.minScalarType

#
np.minScalarType(x)

The smallest dtype that holds the value of a JS scalar or a 0-d array (unsigned integers preferred for non-negative values; floats sized by NumPy's thresholds). Arrays with ndim > 0 return their dtype. JS numbers count as integers only when they are safe integers; use a bigint beyond 2^53.

NumPynumpy.min_scalar_type

Returns

DType

Example

TypeScript
np.minScalarType(10).name;   // => "uint8"
np.minScalarType(-129).name; // => "int16"
np.minScalarType(3.1).name;  // => "float16"
np.minScalarType(1e50).name; // => "float64"
TypeScript declaration
np.minScalarType(a: NDArray | JSScalar): DType

np.isdtype

np.isdtype(dtype, kind)

Array API dtype test. kind is a DType, one of "bool", "signed integer", "unsigned integer", "integral", "real floating", "complex floating", "numeric", or an array of these. dtype must be a DType object.

boolean

Example

TypeScript declaration

np.commonType(...arrays)

The float or complex dtype all inputs convert to (integers count as float64; bool raises DTypeError). NumPy returns a scalar type; this returns a DType.
