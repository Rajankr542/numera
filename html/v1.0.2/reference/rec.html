API reference

Record arrays (np.rec)

Lightweight structured record arrays as named NDArray columns. np.recarray is the class constructor; np.rec is the module namespace.

NameSummary
np.recarrayCreate a zero-filled record array with named fields.
np.fromarraysBuild a record array from a list of column arrays.
np.fromrecordsBuild a record array from a list of row tuples.
np.rec.arrayFlexible record array constructor.
np.find_duplicateReturn values that appear more than once in list.

np.recarray

#
new np.rec.recarray(shape, {names, formats})

Create a zero-filled record array with named fields. np.recarray is also exported at the top level.

NumPynumpy.recarraynumpy.rec.recarray

Parameters

shapenumber | number[]
Number of records, or shape array.
[options.names]string | string[]
Field names.
[options.formats]string | string[]
Format strings (e.g. "float64", "i4").

Returns

recarray

Example

TypeScript
const r = new np.rec.recarray(3, { names: ["x", "y"], formats: ["float64", "int32"] });
r.field("x").shape; // => [3]
r.field("y").dtype.name; // => "int32"
TypeScript declaration
new np.recarray(shape: number | number[], opts?: RecArrayOptions | undefined)

np.fromarrays

#
np.rec.fromarrays(arrayList, {names, formats})

Build a record array from a list of column arrays.

NumPynumpy.rec.fromarrays

Parameters

arrayListArrayLike[]
One array per field.
[options.names]string | string[]
Field names.
[options.formats]string | string[]
Optional format strings.

Returns

recarray

Example

TypeScript
const r = np.rec.fromarrays([np.array([1, 2, 3]), np.array([4.0, 5.0, 6.0])], { names: ["x", "y"] });
r.field("x").toArray(); // => [1, 2, 3]
r.field("y").toArray(); // => [4, 5, 6]
TypeScript declaration
