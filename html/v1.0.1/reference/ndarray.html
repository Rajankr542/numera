API reference

NDArray

Every function returns an NDArray, a handle to data held in native memory. Read the values with toArray(), item() or toTypedArray().

NameSummary
np.attributesRead-only array metadata.
a.toArrayCopies the data into nested JS arrays.
a.itemReturns a single element as a JS number or boolean.
a.toTypedArrayCopies the data into a TypedArray of the matching element type (BigInt64Array for int64).
a.reshapeSame data with a new shape.
a.TTransposed view with no copy.
a.astypeCopy converted to another dtype.
a.copyDeep, C-contiguous copy of the array.
a.toStringNumPy-style representation, also used by console.log.

np.attributes

#
a.shape · a.ndim · a.size · a.dtype · a.strides · a.itemSize · a.nbytes · a.flags

Read-only array metadata. strides are in bytes. flags holds cContiguous, fContiguous, writeable and ownData.

NumPynumpy.ndarray.shapenumpy.ndarray.ndimnumpy.ndarray.sizenumpy.ndarray.dtypenumpy.ndarray.stridesnumpy.ndarray.itemsize

Returns

number[] | number | DType | ArrayFlags

Example

TypeScript
const a = np.zeros([2, 3], { dtype: "float32" });
a.shape;    // => [2, 3]
a.ndim;     // => 2
a.size;     // => 6
a.itemSize; // => 4
a.nbytes;   // => 24
a.strides;  // => [12, 4]

a.toArray

#
a.toArray()

Copies the data into nested JS arrays. int64/uint64 values beyond 2^53 lose precision; use toTypedArray() for those. Complex arrays throw NotImplementedError; use toTypedArray() to read them.

Returns

NestedArray

Example

TypeScript
np.arange(4).reshape(2, 2).toArray(); // => [[0, 1], [2, 3]]

a.item

#
a.item([...index])

Returns a single element as a JS number or boolean. With no index, the array must have exactly one element.

NumPynumpy.ndarray.item

Parameters

[...index]number[]
One integer per axis (negative counts from the end).

Returns

number | boolean

Example

TypeScript
const a = np.array([[1, 2], [3, 4]]);
a.item(1, 0);      // => 3
np.sum(a).item();  // => 10
TypeScript declaration
a.item(...index: number[]): number | boolean

a.toTypedArray

#
a.toTypedArray()

Copies the data into a TypedArray of the matching element type (BigInt64Array for int64). Complex arrays come out interleaved as [re, im, re, im, ...].

Returns

ArrayBufferView

Example

TypeScript
const t = np.array([1, 2, 3], { dtype: "float32" }).toTypedArray();
t instanceof Float32Array; // => true

a.reshape

#
a.reshape(shape) / a.reshape(...dims)

Same data with a new shape. Returns a view when the layout allows it. One dimension may be -1 and is then inferred.

NumPynumpy.ndarray.reshape

Parameters

shapenumber[] | ...number
New dimensions.

Returns

NDArray

Example

TypeScript
np.arange(6).reshape(2, 3); // => [[0, 1, 2], [3, 4, 5]]
np.arange(6).reshape([-1, 2]).shape; // => [3, 2]
TypeScript declaration
a.reshape(shape: number | Shape, ...rest: number[]): NDArray

a.T

#
a.T · a.transpose([...axes])

Transposed view with no copy. transpose() reverses the axes, or permutes them in the order given.

NumPynumpy.ndarray.Tnumpy.ndarray.transpose

Returns

NDArray

Example

TypeScript

a.T; // => [[1, 4], [2, 5], [3, 6]]
np.zeros([2, 3, 4]).transpose(1, 0, 2).shape; // => [3, 2, 4]

a.astype

#
a.astype(dtype)

Copy converted to another dtype. Float → int truncates toward zero, as in NumPy.

a.copy

#
a.copy()

Deep, C-contiguous copy of the array. ravel() flattens to a view when possible; flatten() always copies.

NumPynumpy.ndarray.copy

Returns

NDArray

Example

TypeScript
const a = np.array([[1, 2], [3, 4]]);
const b = a.copy();
np.mayShareMemory(a, b); // => false
a.T.flatten();           // => [1, 3, 2, 4]
TypeScript declaration
a.copy(): NDArray
