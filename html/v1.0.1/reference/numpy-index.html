Names marked documented have a full reference entry with an example. For the others, open signature to see the TypeScript declaration, and follow the NumPy link for the semantics, which numera mirrors.

The JavaScript name is the NumPy name in camelCase, and Python keyword arguments become an options object. The compatibility page lists every documented difference from NumPy.
