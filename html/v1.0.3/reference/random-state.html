np.get_state

#
np.random.get_state()

Return the internal state of the global RandomState as a bigint array (MT19937 words). Can be restored with set_state. Equivalent to numpy.random.get_state.

NumPynumpy.random.get_state

Returns

bigint[]

Example

TypeScript
const state = np.random.get_state();
typeof state; // => "object"

np.random.get_state(): bigint[]

np.random_integers

#
np.random.random_integers(low, high?, size?)

Return random integers from low (inclusive) to high (inclusive). If high is null, returns integers in [1, low]. Deprecated in NumPy — use randint instead. Equivalent to numpy.random.random_integers.

NumPynumpy.random.random_integers

Parameters

lownumber
Lowest integer (or highest if high omitted).
[high]number | null
Highest integer (inclusive).
[size]number | number[]
Output shape.

Returns

NDArray | number

Example

TypeScript
np.random.random_integers(5).valueOf() <= 5; // => true
TypeScript declaration
