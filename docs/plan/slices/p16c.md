# P16C — np.strings and np.char (D-210–D-219)

## Goal
Implement `np.strings` (46 names) and `np.char` (52 names) using a pure-TS
`StringArray` wrapper class. No new C++ DType required. See D-210.

## Slices

| Slice | Content | Status |
|-------|---------|--------|
| P16C-1 | D-210 decision entry; `StringArray` class (shape, ndim, size, dtype, flat, toArray, toString) + slice P16C-1 doc | ✅ |
| P16C-2 | String ops on StringArray: case (capitalize/upper/lower/swapcase/title), padding (center/ljust/rjust/zfill), strip (strip/lstrip/rstrip), expand (expandtabs) | ✅ |
| P16C-3 | String search/test: find/rfind/index/rindex/count/startswith/endswith, str_len; boolean predicates (isalnum/isalpha/isdigit/isdecimal/isnumeric/isspace/islower/isupper/istitle) | ✅ |
| P16C-4 | String transform: add/multiply/mod/replace/translate/encode/decode/split/rsplit/splitlines/partition/rpartition/join/slice | ✅ |
| P16C-5 | Comparisons (equal/not_equal/greater/greater_equal/less/less_equal), np.strings module, np.char module; wiring to index.ts + addon.cpp + docs/site/api.mjs | ✅ |
| P16C-6 | Tests (vitest), DECISIONS/PROGRESS/COMPATIBILITY updates | ✅ |

## Decision reference
- D-210: StringArray representation (JS-string object array)
- D-211: np.strings surface (46 names implemented)
- D-212: np.char surface (52 names)
- D-213: divergences (encode/decode/mod/translate are stubs, char-specific classes excluded)
