## Notes
- `np.matrix_transpose` belongs to P6 (NUMPY_PARITY reorder list); P11 only adds
  `linalg.matrixTranspose`. `np.trace`/`np.diagonal` are P8's; `linalg.trace`/
  `linalg.diagonal` reuse them with `axis1=-2, axis2=-1`.
- Batched `lstsq`: NumPy 2.5.3 `lstsq` still rejects stacks ("3-dimensional
  array given"), so it is not added (would diverge from NumPy).
- NumPy differential cases and benchmarks are deferred to the V phase.
