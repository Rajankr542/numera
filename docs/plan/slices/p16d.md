## Design (D-220)

Store datetime64/timedelta64 as int64 NDArray with a TS-level unit string on a
subclass. No new C++ DType entries — arithmetic and formatting are in TS.
C++ busday counting kernel (`native/core/p16d_datetime.cpp`) for
performance-critical inner loops in `is_busday`, `busday_count`, `busday_offset`.

See DECISIONS.md D-220 for full rationale.

## Divergences from NumPy

| Feature | NumPy | numera | Decision |
|---------|-------|--------|----------|
| datetime64/timedelta64 dtype | C-level type with DType enum entry | TS subclass of NDArray storing int64 + unit string | D-220 |
| NaT representation | int64 min (-9223372036854775808) | Same sentinel value used | D-220 |
| Unit conversion in arithmetic | Auto-converts to common unit | Same common-unit promotion | D-220 |
