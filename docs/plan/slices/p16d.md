## Design (D-220)

Store datetime64/timedelta64 as int64 NDArray with a TS-level unit string on a
subclass. No new C++ DType entries — arithmetic and formatting are in TS.
All busday logic is in TypeScript (pure JS loops are fast enough for typical
workloads; no C++ kernel was needed).

See DECISIONS.md D-220 for full rationale.

## Divergences from NumPy

| Feature | NumPy | numera | Decision |
|---------|-------|--------|----------|
| datetime64/timedelta64 dtype | C-level DType enum entry | TS subclass wrapping int64 NDArray + unit string | D-220 |
| NaT representation | int64 min sentinel | Same sentinel | D-220 |
| datetime arithmetic operators | `+`, `-` on arrays | Not wired (use explicit conversions) | D-220 |
| `np.array(["2023-01-15"], dtype="datetime64[D]")` | Creates datetime64 | Use `datetime64()` directly | D-220 |
| `datetime_as_string` timezone | Can show offsets | Always UTC | D-220 |
