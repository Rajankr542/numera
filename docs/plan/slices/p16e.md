## Design notes (D-230)

`np.rec` surface: no new C++ DType. Record arrays are plain JS objects with named
NDArray fields, wrapped by a `recarray` class that supports attribute access.

- `recarray(shape, {names, formats, ...})` – creates zero-filled record array
- `record` – alias for `recarray` (a record scalar is a 0-d recarray)
- `fromarrays(arrayList, {names, formats, titles, byteorder, aligned})` – build from columns
- `fromrecords(recList, {names, formats, ...})` – build from rows
- `format_parser(formats, names, titles, {aligned, byteorder})` – simple dtype-string parser
- `fromfile(file, dtype, shape, {offset})` – delegates to `np.fromfile`; dtype string parsed via format_parser
- `fromstring(string, dtype, shape)` – delegates to buffer/string reading
- `array(obj, ...)` – flexible constructor: wraps `fromarrays` / `fromrecords` / clones
- `find_duplicate(list)` – returns duplicate values in an array/list (TS helper)

For `np` surface: `recarray` and `shares_memory` are exported onto the default `np` object.
